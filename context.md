# Контекст проекта Chess

Unity 6000.3.9f1, доска 8×8, игрок управляет чёрным королём против белых фигур.

## Текущее состояние

- Core: логическая доска, правила перемещения, здоровье фигур и ИИ.
- Presentation: BoardView и PieceView создают и перемещают отображения фигур.
- PlayerInputController: перетаскивание короля и прицеливание дробовика.
- GameBootstrap: после действия игрока ИИ делает до двух ходов разными фигурами; взятие чёрного короля завершает игру.
- Игрок подтвердил работу перемещения обеих сторон в Unity.

## Дробовик

- ПКМ включает/отменяет прицеливание, ЛКМ стреляет, Escape отменяет.
- Конус показывает разброс и максимальную дальность.
- Параметры на PlayerInputController в Inspector: 8 дробин, 1 HP за дробину, полный угол 30°, дальность 5 клеток.
- ShotgunAttack считает случайные лучи в координатах доски, фигура занимает квадрат своей клетки.
- Каждая дробина останавливается на первой фигуре. Весь урон применяется после расчёта попаданий.
- С расстоянием средний урон падает из-за расхождения дробин; дополнительного ослабления урона дробины нет.
- Погибшие фигуры удаляются из доски и отображения, выстрел (включая промах) передаёт ход ИИ.
- Потери HP пока выводятся в Console. Анимация выстрела ещё не реализована.

## Боезапас

- ShotgunAmmo: патронник на 1 патрон и отдельный запас до 5. Начало партии: 1 + 5.
- Выстрел расходует только патронник. Попытка стрелять пустым не тратит ход.
- Успешное перемещение короля сначала добавляет 1 в запас (до 5), затем заряжает пустой патронник из запаса.
- Перезарядка выполняется только при перемещении короля; перезарядка по R удалена.
- ShotgunAmmoView отображает патронник через поле Chamber Image и запас через пять готовых UI Image в Shell Slots. Shell Sprite — общий спрайт патрона; Empty Shell Sprite — необязательный спрайт пустого слота. View меняет image.sprite; если спрайт пустого слота не задан, пустые Image скрываются. Копии не создаются. Текстовый OnGUI удалён. View назначается в поле Ammo View на PlayerInputController; без ссылки используется/создаётся компонент на том же объекте.
- Недопустимое перемещение и отмена прицеливания не меняют боезапас.
